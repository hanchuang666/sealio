# Sealio 图章工具操作手册

Sealio 是一个用于在 PDF 或图片文件上加盖图章的工具。当前项目支持桌面客户端和网页版，两端尽量保持一致的功能体验。

## 适用场景

- 给 PDF 合同、表单、说明文件添加公司图章。
- 给 PNG / JPG / JPEG 图片添加图章。
- 调整图章大小、位置、旋转角度、透明度和混合模式。
- 对多页 PDF 生成骑缝章。
- 导出已盖章的新 PDF 或图片文件。

## 支持的文件格式

### 可打开的文件

- PDF
- PNG
- JPG
- JPEG

### 可上传的图章

- PNG
- JPG
- JPEG

### 可导出的格式

- PDF
- PNG
- JPG
- JPEG

导出格式通常会根据打开文件的原格式自动判断，也可以通过导出文件名后缀控制。

## 快速开始

### 桌面客户端

1. 打开 Sealio 图章工具。
2. 点击顶部左侧的“打开文件”按钮。
3. 选择 PDF 或图片文件。
4. 在右侧上传或选择图章。
5. 在页面上双击或拖拽放置图章。
6. 调整图章位置、大小和属性。
7. 点击顶部“导出”按钮保存新文件。

### 网页版

1. 打开部署后的网页地址。
2. 点击顶部左侧的“打开文件”按钮，或直接拖入 PDF / 图片文件。
3. 在右侧上传或选择图章。
4. 在页面上双击或拖拽放置图章。
5. 调整图章效果。
6. 点击顶部“导出”按钮下载处理后的文件。

> 网页版上传的临时处理文件会保存到服务器临时目录；图章会保存为图章历史，方便后续继续使用。

## 界面说明

### 顶部工具栏

顶部工具栏包含：

- **打开文件**：选择本地 PDF 或图片文件。
- **导出文件**：导出当前激活文件。
- **缩放**：通过滑块或数字输入框调整页面显示比例。
- **页面模式**：在“多页”和“单页”之间切换。

### 文件标签栏

打开多个文件后，会在顶部出现文件标签。

支持操作：

- 点击标签切换当前文件。
- 拖动标签调整文件顺序。
- 点击标签上的 `×` 关闭文件。
- 如果文件存在未导出的改动，关闭时会提示确认。

### 左侧页面栏

左侧显示当前文件的页面缩略图。

支持操作：

- 点击缩略图跳转到对应页面。
- 多页 PDF 会显示全部页面。
- 图片文件通常显示为单页。

### 中间编辑区

中间区域用于预览和编辑当前文件。

支持操作：

- 双击页面：在双击位置放置当前选中的图章。
- 从右侧图章列表拖拽图章到页面：在松开位置放置图章。
- 点击已放置图章：选中图章。
- 拖动已放置图章：移动位置。
- 拖动右下角控制点：缩放图章。
- 拖动顶部控制点：旋转图章。
- 右键已放置图章：打开图章菜单。
- 按 `Delete` 或 `Backspace`：删除当前选中的图章。

### 右侧图章栏

右侧图章栏用于选择和管理图章。

支持操作：

- 查看已上传的图章历史。
- 在“列表”和“卡片”视图之间切换。
- 搜索图章名称。
- 点击图章选中。
- 拖动图章到页面上放置。
- 点击“图章管理”打开管理弹窗。

图章列表采用懒加载策略：先显示图章名称和加载状态，图片缩略图会逐步加载，避免大量图章拖慢页面。

### 属性面板

选中页面上的图章后，右侧属性面板会显示可调整项：

- **混合模式**：控制图章与文档底图的融合方式。
- **不透明度**：控制图章透明程度。
- **大小**：调整图章宽高。
- **旋转**：输入角度精确旋转。
- **X / Y**：精确调整图章坐标。

当前支持的混合模式：

- 正常
- 正片叠底
- 滤色
- 叠加
- 变暗
- 变亮

## 图章操作

### 上传图章

1. 点击右侧“图章管理”。
2. 点击“上传新图章”。
3. 选择 PNG / JPG / JPEG 图章文件。
4. 上传完成后，新图章会出现在图章历史中。

### 选择图章

- 点击右侧图章列表中的图章即可选中。
- 底部状态栏会显示当前图章历史数量和当前状态。

### 放置图章

有两种方式：

1. **双击放置**：先选中右侧图章，然后在页面上双击。
2. **拖拽放置**：从右侧图章列表拖动图章到页面上松开。

新放置的图章默认使用“正片叠底”混合模式，适合大多数印章叠加效果。

### 调整图章

选中图章后可以：

- 直接拖动图章移动位置。
- 拖动右下角控制点调整大小。
- 拖动顶部控制点调整旋转角度。
- 在属性面板中输入精确数值。

### 删除图章

删除方式：

- 选中图章后按 `Delete` 或 `Backspace`。
- 或右键图章，选择“删除图章”。

## 骑缝章

骑缝章用于多页 PDF。

使用步骤：

1. 打开多页 PDF。
2. 放置一个普通图章到任意页面。
3. 右键该图章。
4. 选择“骑缝章”。
5. 系统会根据 PDF 页数切割图章，并自动放置到每一页边缘。

注意：

- 骑缝章只在多页 PDF 中显示入口。
- 生成后每一页会得到一段切割后的图章。
- 骑缝章会继承原图章的不透明度和混合模式。

## 导出文件

点击顶部“导出文件”按钮后，系统会生成带图章的新文件。

### 导出 PDF

- 如果当前文件是 PDF，默认导出 PDF。
- 图章会被写入 PDF 页面中。
- 支持多页 PDF。

### 导出图片

- 如果当前文件是图片，默认导出图片。
- 可以导出 PNG / JPG / JPEG。
- 图片导出会导出当前激活页面。

### 导出后的状态

导出成功后：

- 桌面端会写入你选择的位置，并尝试在文件夹中显示。
- 网页版会触发浏览器下载。
- 当前文件会标记为“已保存”。

## 关闭文件与退出

- 关闭有未导出改动的文件时，会弹出确认提示。
- 退出软件时，如果有多个文件存在未导出改动，也会弹出确认提示。
- 如果确认关闭或退出，未导出的改动不会保留。

## 常见问题

### 为什么右侧图章不是一次性全部显示？

为了避免大量图章拖慢页面，Sealio 会先加载图章列表，再逐步加载缩略图。这是正常现象。

### 为什么上传图章后自动保存到历史？

图章历史用于后续复用。桌面端保存在本地应用数据目录；网页版保存在服务器的图章目录中。

### 为什么双击页面没有放置图章？

请先确认右侧已经选中了一个图章。如果没有选中图章，页面会提示“请先上传或选择图章”。

### 为什么关闭文件时有确认提示？

说明当前文件存在未导出的改动。导出后再关闭，就不会丢失修改。

### 为什么只有多页 PDF 才有骑缝章？

骑缝章需要按页数切割图章并分布到多页边缘，因此只适用于多页 PDF。

## 开发与运行

如果你是开发者，可以使用下面命令。

### 安装依赖

建议使用 Node.js 20（仓库已提供 `.nvmrc`）：

```bash
npm ci
```

### 启动桌面开发模式

```bash
npm run dev
```

### 仅启动前端开发服务

网页版开发需要先在另一个终端启动本地后端：

```bash
npm run dev:backend
```

再启动 Vite；开发服务器和构建预览都会自动代理 `/api` 和 `/files` 请求：

```bash
npm run dev:vite
```

### 构建 Web 前端

```bash
npm run build
```

### 预览 Web 构建产物

```bash
npm run preview
```

### 打包 macOS 客户端

```bash
npm run package:mac
```

### 打包 Windows 客户端

```bash
npm run package:windows
```

## 后端与部署

网页版依赖轻量 Python 后端和 Nginx。

后端能力包括：

- 图章上传。
- 临时文件上传。
- 图章历史元数据读取。
- 健康检查。

主要接口：

- `GET /api/health`
- `GET /api/stamps`
- `POST /api/stamps`
- `POST /api/uploads`

部署相关文件：

- `server/sealio_backend.py`
- `deploy/sealio-backend.service`
- `deploy/nginx-sealio.conf`
- `.github/workflows/deploy-server.yml`

推送到 `main` 后，GitHub Actions 会自动构建并部署网页版到服务器，通常不需要手动 SSH 重启服务。
